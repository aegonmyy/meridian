# AgentConsumer
[Git Source](https://github.com/aegonmyy/meridian/blob/04fdcb3887d6bfe7076e798735b94bee541e7ecf/src/AgentConsumer.sol)

**Inherits:**
Ownable

**Title:**
AgentConsumer

Thin entry point for the off-chain agent to submit allocation proposals to the Rebalancer

The off-chain agent is a cron job wallet that periodically fetches APYs from Aave,
Compound, and Morpho, computes the optimal allocation, and calls proposeAllocation.
This contract enforces access control before forwarding to the Rebalancer.
No Chainlink Functions dependency — simpler, cheaper, and operator controlled.
Architecture: off-chain script → AgentConsumer → Rebalancer → HubVault → SpokeVaults


## Constants
### REBALANCER
Address of the Rebalancer contract that validates and executes proposals

Immutable — set once at deployment. AgentConsumer forwards all proposals here.


```solidity
address public immutable REBALANCER
```


### AGENT
Address of the off-chain agent wallet (cron job EOA)

Immutable — the EOA that signs and submits allocation proposals on a schedule.
Authorized alongside owner to call proposeAllocation.


```solidity
address public immutable AGENT
```


## Functions
### onlyAgent

Restricts access to the AGENT wallet or the contract owner


```solidity
modifier onlyAgent() ;
```

### constructor

Deploys AgentConsumer with immutable Rebalancer and agent references

Ownable(_owner) runs before the body — zero _owner reverts with
OwnableInvalidOwner before InvalidConstructorArguments is checked.
Zero _rebalancer or _agent reverts with InvalidConstructorArguments.


```solidity
constructor(address _rebalancer, address _agent, address _owner) Ownable(_owner);
```
**Parameters**

|Name|Type|Description|
|----|----|-----------|
|`_rebalancer`|`address`|Address of the Rebalancer contract|
|`_agent`|`address`|Address of the off-chain agent EOA (cron job wallet)|
|`_owner`|`address`|Address of the contract owner — should be a multisig before mainnet|


### proposeAllocation

Forwards an allocation proposal from the off-chain agent to the Rebalancer

Only callable by AGENT or owner. All proposal validation occurs in the Rebalancer —
this contract is a pure access control wrapper. If Rebalancer reverts (cooldown,
invalid allocation, below threshold etc) this call reverts too.
Emits AllocationProposed only on success.


```solidity
function proposeAllocation(AllocationProposal calldata proposal) external onlyAgent;
```
**Parameters**

|Name|Type|Description|
|----|----|-----------|
|`proposal`|`AllocationProposal`|The AllocationProposal struct generated by the off-chain agent containing current and proposed allocations, APYs, chain selectors, and protocol ids|


## Events
### AllocationProposed
Emitted when a proposal is successfully forwarded to the Rebalancer

Does not indicate the proposal was accepted — Rebalancer may still revert
if guards fail. Emitted after the Rebalancer call succeeds.


```solidity
event AllocationProposed(address indexed caller, uint256 timestamp);
```

**Parameters**

|Name|Type|Description|
|----|----|-----------|
|`caller`|`address`|Address that submitted the proposal — either AGENT or owner|
|`timestamp`|`uint256`|Block timestamp when the proposal was submitted|

## Errors
### NotAgent
Thrown when caller is neither AGENT nor owner


```solidity
error NotAgent();
```

### InvalidConstructorArguments
Thrown when constructor receives a zero address for any argument

Note: _owner == address(0) reverts with OwnableInvalidOwner from the Ownable
parent constructor before this check is reached


```solidity
error InvalidConstructorArguments();
```
