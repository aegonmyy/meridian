    FX-2: reconcileTransit must decrement inTransitToSpoke (MUST)
    
    inTransitToSpoke[selector] incremented in _sendToSpoke, decremented only in
    _handleDepositCallback. A reconciled leg is by definition one whose confirm
    never arrives, so its decrement never happened — after any reconcileTransit,
    the safe removeSpoke path reverted SpokeHasInFlightLegs forever for that
    selector, forcing forceRemoveSpoke (the loud emergency hatch) as the
    routine removal tool for exactly the dead-lane scenario reconcileTransit
    exists to clean up. Root cause: reconcileTransit only had the messageId; the
    hub never stored messageId -> selector.
    
    Fix: replaced the parallel inTransitSince mapping with
    mapping(bytes32 => TransitLeg) transitLegs, where TransitLeg{selector,sentAt}
    is recorded at send time (_sendToSpoke) and fits one slot. reconcileTransit
    now reads the selector from the stored struct (never an owner-supplied
    parameter — unverifiable) and decrements inTransitToSpoke[leg.selector]
    alongside releasing inTransitAmount. Also fixes the WI-5 review's hygiene
    note that inTransitSince was never deleted on the normal
    _handleDepositCallback path (now deletes the whole struct).
    
    Storage layout: slot NUMBERS are unchanged (inTransitAssets=15,
    inTransitAmount=16, transitLegs=17 replaces inTransitSince=17,
    inTransitToSpoke=18, netSentToSpoke=19) but slot 17's per-key VALUE ENCODING
    changed from a plain uint256 timestamp to a packed struct (selector at byte
    offset 0, sentAt at byte offset 8). Updated WI5_TransitReconciliationTest's
    storage-injection helpers to write the packed encoding; audited WI-3's
    slot-8 test, WI-6's out-of-order test, and BaseHubTest's spokeBalances/
    lastReportTimestamp helpers — none touch the changed slot, but added a
    one-line authoritative-layout-command pointer at each per FX-2's brittleness
    note. New regression test proves reconcile -> drain -> removeSpoke now
    succeeds (pre-fix, reverts SpokeHasInFlightLegs even after full drain).

+contract FX2_ReconcileInTransitToSpokeTest is BaseHubTest {
+    /// @notice Reproduces the defect: reconcile a stuck deposit leg, drain the spoke to
+    /// zero balance, then removeSpoke — pre-fix this reverts SpokeHasInFlightLegs forever
+    /// because inTransitToSpoke[selector] was never decremented by reconcileTransit.
+    function test_fx2_removeSpokeSucceeds_afterReconcileAndDrain() public {
+        // Send a deposit, then simulate it getting stuck (never confirmed) by directly
+        // incrementing inTransitToSpoke the same way _sendToSpoke does, alongside a fake
+        // tracked leg — this mirrors "the confirm never arrives" without relying on a
+        // mock spoke plumbing quirk, matching the WI5 test file's established pattern.
+        _sendToSpoke(3_000e6); // real, resolves synchronously; spoke now has 3_000e6
+
+        bytes32 stuckLegId = keccak256("stuck-deposit-leg");
+        uint256 stuckAmount = 500e6;
+        _setInTransitAmount(stuckLegId, stuckAmount);
+        _setTransitLeg(stuckLegId, chainSelector, block.timestamp);
+        _bumpInTransitAssets(stuckAmount);
+        _bumpInTransitToSpoke(chainSelector, 1);
+
+        // drain the spoke's real balance to zero so only the in-flight-legs guard remains
+        bytes32 recallId = _generateMessageId(address(hub));
+        _recallFromSpoke(3_000e6, recallId);
+        assertEq(hub.spokeBalances(chainSelector), 0, "spoke fully drained");
+
+        // still blocked — one in-flight leg remains
+        vm.prank(owner);
+        vm.expectRevert(SpokeHasInFlightLegs.selector);
+        hub.removeSpoke(chainSelector);
+
+        // reconcile the stuck leg (dead lane, provably never arriving)
+        vm.warp(block.timestamp + hub.TRANSIT_RECONCILE_DELAY() + 1);
+        vm.prank(owner);
+        hub.reconcileTransit(stuckLegId);
+
+        assertEq(hub.inTransitToSpoke(chainSelector), 0, "in-flight leg counter released");
+
+        // now the safe removal path must succeed
+        vm.prank(owner);
+        hub.removeSpoke(chainSelector);
+
+        (, bool exists, ) = hub.spokes(chainSelector);
+        assertFalse(exists, "spoke removed via the safe path");
+    }
